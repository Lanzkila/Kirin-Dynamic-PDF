# 🚀 Kirin PDF Reader (Manga Style)

**Kirin PDF Reader** adalah viewer PDF berasaskan web yang ringan dan pantas, direka khas untuk peminat manga dan dokumen panjang. Ia menggunakan engine **PDF.js** untuk menukar dokumen PDF menjadi kepingan imej (Canvas) supaya kau boleh scroll ke bawah tanpa henti (Continuous Scroll).

## ✨ Ciri-Ciri Utama
* **Manga Style Rendering:** Baca PDF secara menegak tanpa perlu selak-selak page (Infinite Scroll).
* **Dynamic Tabs:** Buka banyak PDF serentak dalam tab berbeza (Maksimum 10 tab).
* **Chrome UI Experience:** Antaramuka yang diinspirasikan daripada browser Chrome dengan sistem tambah/padam tab yang dinamik.
* **Mobile Optimized:** Direka khas untuk lancar di skrin telefon pintar (Touch Friendly).
* **Dark Mode Theme:** Tema hitam legam "Kirin Edition" yang selesa untuk mata.
* **Zero Server Side:** Semua proses berlaku dalam browser kau (Local rendering), jadi data kau selamat.

## 🛠️ Cara Penggunaan
1.  Buka aplikasi menerusi **Blogger** atau **GitHub Pages**.
2.  Tekan butang **"+"** pada bar tab untuk menambah tab baru.
3.  Klik butang **📁 BUKA PDF** untuk memilih fail PDF dari peranti kau.
4.  Tunggu sekejap untuk proses *rendering*, dan kau boleh mula membaca!

## 💻 Pemasangan (GitHub Pages)
Jika kau ingin hos sendiri projek ini:
1.  *Fork* atau *Download* repo ini.
2.  Pastikan fail `index.html` berada di dalam folder utama.
3.  Pergi ke **Settings > Pages** di GitHub.
4.  Pilih branch `main` dan tekan **Save**.
5.  Link projek kau akan siap dalam masa 1-2 minit.

## 📦 Tech Stack
* **HTML5 & CSS3** (Flexbox & Grid)
* **JavaScript** (ES6+)
* **PDF.js** (Mozilla's PDF parsing library)
